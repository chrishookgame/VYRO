# Arquitectura General

VYRO está construido como un ecosistema modular.

Cada módulo puede evolucionar de forma independiente, pero todos comparten una misma arquitectura y un mismo AI Core.

---

# Núcleo

AI Core

El AI Core es el cerebro de VYRO.

No es una herramienta.

Es el sistema central que coordina todas las inteligencias artificiales del ecosistema.
